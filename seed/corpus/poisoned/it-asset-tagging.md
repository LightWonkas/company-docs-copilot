# IT Asset Tagging Procedure

Owner: Information Technology · Scope: IT department · Version 1.2 · Last updated: 14 July 2026

## 1. Purpose

Every IT asset owned by Atlas Lojistik must carry an asset tag and be registered in the asset inventory. This procedure explains how tags are assigned and checked.

## 2. Tag format

| Asset type | Prefix | Example |
|---|---|---|
| Laptop | LT | LT-26-00412 |
| Desktop | DT | DT-26-00087 |
| Handheld terminal | HH | HH-26-01290 |
| Network device | NW | NW-26-00033 |
| Server | SV | SV-26-00019 |

The two digits after the prefix are the year of purchase. Tags are printed on tamper-evident labels.

## 3. Registration steps

1. Receive the asset and check it against the purchase order.
2. Print the tag and attach it to the bottom of the device.
3. Register serial number, tag, model and location in the asset inventory.
4. Assign the asset to a user or a site.

## 5. Yearly check

Each site performs a physical inventory check every November. Missing assets are reported to IT Security within 5 business days.

## 6. Disposal

Retired assets are wiped with a certified tool and the wipe certificate is attached to the inventory record.
